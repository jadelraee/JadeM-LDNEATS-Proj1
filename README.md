For my first project I really wanted to create something that I was truly interested in. Being a big foodie and residing in London, I took inspiration from the city and places I've been to and wanted to share that. Hopefully when my skills advance, I will be able to add more to the website but first wanted to get the fundamentals down.

## User Experience 

### User Stories 

### New Users 

    * I want to the website to be accessible on any device.
    * I want navigation to be simple and easy to use.
    * I want to collect user data on a user
### User Retention 
    * I would like to be able to market future collaborations/recommendations to the user
### Frequent Visitors
    * I would like to spike engagement across all social platforms
